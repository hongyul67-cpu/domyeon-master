# 🏭 기초 제도 마스터 아카데미

자동설비 기능사 대비 **기초 제도 학습 게임**입니다. 하나의 HTML 파일로 동작하며, 설치·인터넷 없이 브라우저(휴대폰 포함)에서 바로 실행됩니다.

## 🎮 플레이하기

- **온라인**: https://hongyul67-cpu.github.io/domyeon-master/
- **오프라인**: `index.html` 파일을 브라우저로 열기

## 구성 — 네 부서 + 최종 관문

각 부서는 **배우기(정답을 다 보여 주는 단계)** 로 시작하고 그 뒤에 도전이 옵니다.
네 부서를 다 마치면 자격증 4개, 종합시험까지 통과하면 **마스터 기술자**입니다.
진행 상황은 브라우저에 자동 저장됩니다.

| 부서 | 배우기 | 도전 |
|---|---|---|
| 📐 도면 양식·척도 | 5쪽 — KS 부문 카드 · **A0을 직접 접어 A4까지** · 양식 5요소 켜고 끄기 · **표제란 칸별 설명** · 척도 비교 | 용지 고르기 · 척도 계산 · 양식·표제란 (각 8문제) |
| 📏 선의 종류 | 6쪽 — 굵기 비율 1:2:4 · 선 6종 · 1점/2점 쇄선 · **겹칠 때 우선순위** · 자주 하는 실수 | 선 식별 · 오류 찾기 · 짝 맞추기 · 빈칸 채우기 |
| 📏 치수 기입·읽기 | 10쪽 — 치수 4요소 · 화살표 3:1 · 지시선 60° · 보조기호 9종 · **기입 원칙과 실수** | 기호 해독 · 계측 · 정밀 계산 · 품질 검사 (도크 4곳) |
| ⚙️ 기계요소 약도 | — | 부품 창고 정리 · 부품 감별 · 고장 진단 · 실전 종합 정비 |
| 🎯 종합 자격시험 | — | **30문항** — 양식 · 척도 · 선 · 치수 · 기계요소 5영역 혼합. 70%(21문항) 이상이면 합격 |

**종합 자격시험은 부서 진행과 상관없이 언제나 열려 있습니다.** (2026-09-08)

## 특징

- 계급 시스템(견습생 → 마스터 기술자 6단계)과 자격증 보관함
- 시험 중에는 정답을 알려 주지 않고, 끝나면 **오답노트**로 한꺼번에 확인
- 휴대폰 터치 최적화 — 넓은 터치 영역, 선택 후 **제출** 방식(실수 클릭 방지)
- 진행 상황 자동 저장(localStorage) · `?rc=` 링크로 열면 결과를 선생님 시트로 제출
- 📽️ 수업 슬라이드(`lesson.js` + 공용 `board-pro.js`) — 교실 화면용

## 합친 내력

2026-09-08, 제도 허브 1단계에 흩어져 있던 세 도구를 이 한 곳으로 합쳤습니다.
학생이 어느 카드를 눌러야 할지 헷갈리고, **치수 내용이 두 도구에 반씩 겹쳐 있었기 때문**입니다.

| 옛 도구 | 어디로 갔나 |
|---|---|
| 도면 양식·척도 마스터 (`paper-scale-master`) | **부서 1** 로 흡수 (배우기에 표제란 쪽 추가) |
| 치수기입 마스터 (`dimensioning-master`) | **부서 3의 배우기** 로 흡수 (요소·보조기호·기입 원칙) |
| 도면읽기 마스터 (`domyeon-master`) | 이 저장소 — 껍데기와 주소를 그대로 씀 |

옛 저장소와 주소는 **지우지 않았습니다.** 이미 나눠 준 링크는 계속 열립니다.
다만 링크 허브·제도 허브의 카드는 이 합본 하나로 정리했습니다.

## 파일

- `index.html` — 통합 실행본. 이 파일 하나만 씁니다.
- `lesson.js` — 수업 슬라이드 원고 (화면은 `links/board-pro.js` 공용)
- `rubric.json` — 평가 기준 (양식·척도 항목 포함)

합치기 전의 개별 게임 3개(`선의_종류_마스터.html` · `치수_읽기_마스터.html` ·
`기계요소_약도_마스터.html`)는 통합본으로 넘겨주는 **안내 페이지**로만 남아 있습니다.
`?rc=` 같은 값도 그대로 들고 넘어갑니다.
